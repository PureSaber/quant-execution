# 衍生品研究账户

`quant_execution.derivatives.DerivativeAccount` 复用 `ExactAccountLedger`，不另建现金账本。支持整数手数、显式费用及不利跳价、原子多腿成交、正价期货每日结算、现金期权到期、明确的美式提前行权，以及期权标的的实物交付。接口不发送订单。

账户只处理单币种。价格、数量、费用和过账均为 FixedPoint，交易按 ID 幂等；变更内容复用 ID、倒序时间、资金不足或缺失保证金拒绝并回滚。期权是权利金现金资产，可多空持有；交割价格乘合约乘数后进入账本。普通股票账户原有禁止空头的规则保持有效，只有显式研究交割标的开放有符号持仓。

保证金采用逐合约声明金额相加，期货双向计提，期权只对空头计提。没有 SPAN、跨腿抵消或交易所保证金认证。实物交割形成的负现金或空头股票会明确标记资金／借券边界，不自动借贷或伪造强平。期货期权实物交割要求已有同乘数的标的期货定义。

`derivative_replay.replay` 在日线观察可用后决策，下一条观察的开盘价模拟成交。完整组合才成交；缺失持仓估值、成交量为零、缺失期货结算价或保证金突破都会停止。日线时间戳是观察时间，不能冒充逐笔成交时刻。期权到期需要精确到期时刻的标的 fixing，否则应提前平仓。物理交割在账户层可单独研究，通用日线回放要求到期前平仓；不会假设后续标的行情或借券。

报告导出 `nav.csv`、`fills.csv`、`positions.csv`、`ledger.csv` 和 `study.json`。逐币种借贷平衡逐笔检查；`artifacts.json` 固定所有报告文件 SHA-256，`verify_artifacts` 检查文件变化和账本平衡。输入、代码与配置固定后可以另用新目录重跑比较，哈希校验本身不代替独立市场验收。

当前边界：正价成交/估值和结算，最多 8 位十进制账户精度；不支持负价期货交易、组合保证金、自动美式最优行权、外汇估值或实盘执行。合成样本仅验收工程，不证明盈利或可投资性。
